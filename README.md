# Ziki Whimsical

A separate React and TypeScript experiment based on the completed Ziki redesign.

Run npm install, then npm run dev (port 5174). Build with npm run build.

Effects: larger eyes in the Overview O with paired blinks over 30 seconds; a one-time settling bell when pending decisions first appear; agent avatar acknowledgement on hover or keyboard focus; animated checkmark on approvals; brief sparkles when all decisions are cleared. Reduced-motion preferences disable all five animations. Theme preference uses a separate localStorage key.

Sample data only. No real agents or backend integrations. The original submission files are unchanged.
